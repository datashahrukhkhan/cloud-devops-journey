# Cloud & DevOps Journey 

My hands-on learning journey in Cloud Computing, AWS, Linux, Docker, Git, Jenkins, Terraform, and Kubernetes.

I am building my understanding through structured notes, practical labs, troubleshooting, and projects. This repository follows a **topic-based learning approach**, not a day-based schedule.

## Learning Goals

- Understand Cloud Computing and AWS fundamentals.
- Practise Linux commands and basic shell scripting.
- Learn AWS services and website hosting.
- Build applications using Docker and Docker Compose.
- Understand Git, GitHub, and CI/CD with Jenkins.
- Learn Infrastructure as Code using Terraform.
- Develop foundational Kubernetes skills.
- Prepare for Cloud and DevOps interviews.

## Learning Method

For each topic, I aim to document:

- Concepts explained in my own words
- Commands and practical examples
- Hands-on labs and troubleshooting
- Interview questions and answers
- Lessons learned and improvements

## Security Practices

- Never publish AWS credentials, passwords, private keys, or sensitive account details.
- Keep `.pem` files outside this repository and outside OneDrive.
- Check AWS costs before launching resources.
- Terminate lab resources when finished and maintain billing alerts.

## Progress

Learning is ongoing. Topics and projects will be added as I study, practise, and verify my understanding.

**My principle:** Understand the concept, practise it, explain it, and document meaningful progress.
